## 最新对照结果与下一步

用户已运行原 Qt 备份及其内嵌旧后台，反馈旧版同样无法识别。该故障在不加载新增记录功能时仍存在，应优先定位两版共用的采集运行环境。原 Qt 测试通过子进程临时选择备份，未覆盖当前程序；退出旧界面后，正常执行 `sh ./run_ui_voice.sh` 即回到带历史页的新版。

用户补充：SD 卡被用于添加仪器相关内容，进一步确认只是添加了两个通信相关的包；没有提供覆盖启动镜像的证据。若仅存放文件而未安装、运行或替换启动文件，该变化的优先级降低，不应断言 SD 镜像损坏。

此前同一故障中，固定时长录音出现 300/300、350/350 帧高于 0.01 门限。结合原分句器实现，应重点区分持续高能量输入导致无法获得 0.8 秒句尾静音、音频芯片/驱动运行状态，以及设备路由或其他音频进程变化。先在助手关闭时记录 uname、/proc/asound/cards、/proc/asound/pcm 和 ps w；若进行完整掉电验证，先将仍存在的 `/tmp/labmate_ui_mic_probe.raw` 复制到持久目录，避免丢失已有证据。当前不改变字节序、门限、声道、模型或原语音源码。
