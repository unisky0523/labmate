# 扫频响应曲线语音操作

每轮先点“开始识别”再说话；核对屏幕解析结果后，说“确认保存”或点确认按钮。需要取消时说“取消”。

| 顺序 | 说的话 | 效果 |
| --- | --- | --- |
| 1 | 配置扫频起始频率一百赫兹终止频率十千赫兹时间十秒幅度一伏峰峰值 | 保存 100 Hz→10 kHz、10 秒、1 Vpp 的线性扫频配置，输出保持关闭 |
| 2 | 开始扫频 | 确认后按上次成功配置开启 DG4102 CH2 输出，并记录 HOST4 示波器 CH1 的实测频率与峰峰值 |
| 可选 | 查询信号发生器状态 | 回读输出与扫频参数 |
| 结束 | 停止扫频 | 确认后关闭输出并退出扫频模式；未结束的响应观测保存为部分结果 |

若已有合适的扫频参数，可直接从“开始扫频”开始。也支持完整句：“开始扫频起始频率一百赫兹终止频率十千赫兹时间十秒幅度一伏峰峰值”。

曲线查看用触屏：**历史记录 → 刷新 → 打开本次“开始扫频”记录 → 查看响应曲线**。不需要另说截图指令，也没有“查看响应曲线”的语音口令。短时间内没有足够有效频率点时只保留数据和失败原因，不生成虚构图片。

示波器保持自动/普通运行，使用 CH1。连续扫频得到近似的 Vpp—频率曲线；时间越短，通常有效测量点越少。一次观测按配置的一次扫频时长结束，发生器连续扫频输出仍保持原设置，需结束输出时再说“停止扫频”。

“暂停扫频”和“继续扫频”仍可控制输出，但“继续扫频”不自动创建新响应观测；重新记录曲线请使用“开始扫频”。
