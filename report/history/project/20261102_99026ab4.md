## 使用方式

| 语音 | 实际行为 |
| --- | --- |
| 读取数据 | 先读取并分仪器显示本次真实读数；确认保存当前快照，取消不写实验历史。 |
| 记录数据 | 核对确认后读取两台仪器并保存。 |
| 拍一下波形 | 核对“示波器屏幕截图”提示后确认；通过 USB 保存屏幕图片并归档。 |
| 记录电压三点三伏等人工报数 | 沿用原流程，保存人工语音报数，来源与仪器数据分开。 |
| 保存波形 | 明确提示尚无原始波形采样点接口，不把截图说成采样数据。 |
| 连续记录、明确调用摄像头 | 本轮未接入，明确拒绝对应动作，不归档成正常采集结果。 |

启动命令：

```sh
sh /home/root/labmate_ui_test/run_ui_instruments.sh
```

`run_ui_voice.sh` 发现 `instruments.json` 后也自动启用仪器调度。Qt 仍使用原有“开始识别／确认保存／取消／历史记录”操作。
