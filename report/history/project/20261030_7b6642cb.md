```python
recognized_at = ...
```

## 9. 原记录格式与复用原则

冻结源码 `asr_runtime/main.py` 提供 `validate_reading`、`save_record`、`read_record`。

- schema_version 为 2，record_id 是 32 位十六进制 UUID。
- 手动报数 record_kind 为 manual，source 为 manual_voice，is_simulated 为 false。
- measurements 保存 quantity、十进制字符串 value 和 unit；不要把 0 或小数精度处理丢失。
- 电压支持 V/mV，电流支持 A/mA；遵循原校验逻辑。
- 保存 original_text、input_at、confirmed_at、audio_path 等溯源信息。
- read_record 会合并 annotations 目录中的异常/作废事件；不能只读 JSON 而丢掉标注状态。
- 原始语音工程作为基准保留，通过适配器和独立副本集成，不覆盖用户指定的原始目录。
