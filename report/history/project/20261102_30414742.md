# 显示屏桌面入口

目标：板卡独立供电后，从自带显示屏的厂商桌面点击“实验助手”，进入已有语音、仪器读取和历史截图界面；关闭助手后返回桌面，可再次打开。开发用串口命令仍可使用。

本轮改动：

- 新建工作副本 `work/vendor_desktop_labmate`，原厂商参考源码保持原样。桌面右下角增加 170×60 的“实验助手”按钮，原有 20 个应用及四页菜单保持原编号。按钮对应独立子进程，运行期间防止重复启动，关闭或启动失败后恢复桌面。
- 新增 `tools/run_ui_desktop.sh`，调用正式仪器/语音启动入口。
- `tools/run_ui_test.sh` 识别 `LABMATE_DESKTOP_CHILD=1`：桌面点击启动时保留父桌面，由父桌面恢复显示；串口独立启动仍沿用停止并恢复桌面的原流程。
- 新增 `tools/install_desktop_entry.py`：核对已知原版桌面、先保存并验证原件，再原子替换；提供回滚。
- 串口上传器新增 `-DesktopEntry`，将程序先上传到助手目录暂存。
