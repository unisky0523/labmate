# DG4102 信号发生器语音接入

当前版本：`labmate_ui_voice_20261103_dg4102_v1`，在已固定的 `20261103_units_v1` 基础上增加信号发生器控制。旧版本归档保留，可回滚。

## 接线与入口

DG4102 背面 **USB DEVICE** 口连接板卡 **HOST2**；使用发生器 **CH2** 输出。HOST2 是 USB 物理接口，CH2 是信号输出通道，两者不是同一编号体系。当前设备序列号 `DG4E184950519`，实测 Linux USB 路径 `1-1.2`；运行时核对路径、序列号和设备型号，不依赖 `/dev/usbtmcN` 编号。

桌面打开“实验助手”，点“开始识别”，说指令，核对屏幕参数，再手动点“确认保存”或说“确认”。配置和开启输出均由确认动作提交；识别本身不设置仪表。状态查询可以先回读，确认只归档这次回读。

## 支持的指令

| 说法 | 行为 |
| --- | --- |
| 查询信号发生器状态／查询扫频状态 | 查询 CH2 输出、波形、幅度、偏置、负载设置和扫频状态，不改变设置 |
| 配置扫频从一百赫兹到一万赫兹时间五秒幅度一伏峰峰值 | 配置 100 Hz → 10 kHz、5 s、1 Vpp，输出保持关闭 |
| 配置对数扫频起始频率一百赫兹终止频率一万赫兹时间五秒幅度一伏峰峰值 | 同上，改为对数间距；“线性扫频”也支持 |
| 开始扫频 | 展示上次成功配置的参数；确认后重新配置并开启输出。尚无成功配置则拒绝，不猜测幅度 |
| 开始扫频从一百赫兹到一万赫兹时间五秒幅度一伏峰峰值 | 展示本句参数；确认后先配置并验证输出 OFF，再开启输出 |
| 暂停扫频 | 关闭输出，保留扫频配置；发生器内部扫频时序可能继续 |
| 继续扫频／恢复扫频 | 先回读当前设置供核对；确认时再次核对设置未变化，才恢复输出；不保证从暂停位置继续 |
| 停止扫频 | 关闭输出并关闭扫频模式；后续“继续扫频”会拒绝，应“开始扫频”重新配置 |
| 关闭信号输出 | 关闭输出，保留当前模式 |
| 开启信号输出 | 先展示当前回读参数；确认时重新核对设置，未改变才开启 |
| 设置正弦波频率一千赫兹幅度一伏峰峰值 | 配置固定频率正弦波，输出保持关闭 |
| 设置信号发生器频率为五千赫兹／设置信号发生器频率为5KHZ | 先回读其余参数并展示，保留已回读幅度、偏置和负载；确认后切为 5 kHz 固定正弦波，输出关闭 |
| 设置信号发生器峰峰值一伏／设置信号发生器峰峰值1V | “峰峰值”已明确幅度定义，可直接说伏；保留当前正弦/扫频模式及已回读参数，确认后配置并关闭输出 |
| 触发扫频 | 仅对已经设置为手动触发的扫频发送一次触发；本版语音配置默认内部触发，不会自动改成手动触发 |

可加前缀“通道二”。当前配置只启用 CH2，明确要求 CH1 的指令会拒绝。频率支持赫兹、千赫兹、兆赫兹和 Hz/kHz/MHz；支持“一万赫兹”等明确整数。“一万二”有歧义，会拒绝。幅度必须明确为伏峰峰值、毫伏峰峰值或 Vpp/mVpp，不将 Vrms、普通伏或 dBm 自动转换为 Vpp。参数可改，不限于示例。

默认偏置为 0 V、负载设置 highz、内部触发；会在确认界面明确显示。负载设置不代表实际电路终端阻抗。范围与队员 C 驱动一致：频率 1 µHz—100 MHz，扫频时间 0.001—300 s，幅度 0.02—10 Vpp；高频、电压加偏置的限制在解析与驱动两层核对。

“确认保存”按钮沿用原界面文字。对信号发生器，它表示执行已核对的控制并保存实际回执，不是仅把一句指令写入历史。执行失败也保存为失败记录，不显示成功或伪造电压、电流数据。状态回读成功不等于实际电信号已经测量验证。

单项频率/峰峰值设置会先回读，确认时在设备锁内再次比较设置是否改变，改变则拒绝本轮控制。当前非正弦波或幅度单位不是 VPP 时不自动换算，提示先完整设置正弦波。单改频率会退出扫频；单改峰峰值可保留扫频起止频率、时间、间距、触发方式。修改完成保持输出关闭，需要输出时再明确说“开启信号输出”。

## 上板与验证

已部署根目录 `/home/root/labmate_ui_test`；驱动 `/home/root/labmate_ui_test/dg4102_driver`，端口绑定在其 `c_instrument/board_config/dg4102_host2.json`。首次接入或实际更换物理端口时，在确认接好 HOST2 后运行：

```sh
cd /home/root/labmate_ui_test/dg4102_driver
sh c_instrument/run_dg4102_board.sh --bind-host2
sh c_instrument/run_dg4102_board.sh --channel 2 status
```

后续同位置连接不需要每次重新绑定。信号发生器掉线不会自动改绑定其他设备。

Windows 关闭助手后更新：

```powershell
& .\tools\upload_ui_serial.ps1 -PortName COM6 -RealAsr -RecordsOnly -Instruments -MeasurementUnits -GeneratorControl
```
