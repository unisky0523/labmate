# 撤销与历史清除

使用方法：

- 语音“撤销上一条数据／记录”：显示要撤销的数据与时间，核对后点击“确认保存”或说“确认”。历史中的目标记录变为“已撤销”，不会新增一条撤销指令记录。取消不修改数据。
- 清除单条：历史记录 → 点选记录 → 清除这条记录 → 确认清除。
- 清除全部：历史页右上角“清除全部记录” → 核对数量 → 确认清除。

清除后记录从历史列表移除，重启仍保持清除状态；新保存的记录正常显示。多个旧目录中的同编号副本一起处理。原始记录和图片保留为审计备份，撤销/清除状态保存在当前记录目录的 `history_edits.json`。

改动：`record_store.py` 实现目标绑定、持久撤销和历史清除；`backend.py` 调度修改并返回实际结果；`main.cpp` 增加按钮、确认弹窗及刷新；`asr_grammar.py` 补充“撤销上一条数据／作废上一条数据”。PCM little 解码、模型、声音门限、仪器通信及桌面入口保持原设置。

防止误改：撤销确认绑定预览时的编号；保存后不会误改后来新增的数据；清除全部校验历史版本，列表发生变化时要求刷新并重新确认；识别或保存期间不允许清除。修改原子写入，写入失败不报告成功。
