## 本轮实际执行结果

- ZIP CRC、21 个原始文件与独立附件 README 一致性通过。源字节及原文件名由 `build/source_map.json` 保留。
- 四个 Python 脚本语法检查通过。用标准库整数模型重算 6000 个固定输入，全部匹配黄金输出；无需重新安装 SciPy。
- 技能中的 `asr_audio_frontend.v`、`fir_coeff.vh` 与主 FPGA 工程逐字节一致。
- 使用本机 **XSim 2026.1** 执行原回归脚本：滤波/旁路各两轮，每轮 6000 字，**24,000 次比较通过**，覆盖输出反压稳定性、声道/元数据、复位和样本计数。队员所述 2020.2 结果与本轮工具版本分别记录；主 Vivado 工程的原构建版本仍为 2020.2。
- 真实报告回放得到 WNS +0.135 ns、WHS +0.029 ns、Slice 4392/4400。审计预期返回 2：约束内时序、容量和 DRC 门限通过，但 no_clock=214、未约束内部端点=492、no_input_delay=21、no_output_delay=42，需人工复核。
- PYNQ 离线正例、六类错误反例和模拟 Overlay 调用通过；模拟调用确认 `download=False`，未下载实际 Overlay、未访问板卡。

原始结果：`sim/results/fpga_skill_checks.json`、`fpga_skill_xsim.log`、`vivado_skill_audit.json`、`pynq_skill_snapshot.json`。重生成滤波器系数/频响仍需 NumPy 与 SciPy，本轮未执行该覆盖操作；随包固定向量已独立核算。

## 使用和验收边界

先从根目录运行 `python -B build/prepare.py --out /path/to/labmate_repro --component skill`，再按恢复后的三个 SKILL.md 执行。报告审计返回 2 是明确的人工复核结论；不能改写成“全部时序无问题”。

定点模块的仿真不替代麦克风、I2S、Linux 音频和识别器的整机验证。PYNQ 技能已有通用接口和离线验证，后续宜补真实 `.bit/.hwh`、实板及跨板记录来增强加分证据。本项目十组 ASR 耗时继续按团队手动实测保存，与技能的通用示例快照分别说明。
