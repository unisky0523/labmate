# 验收状态与整理边界

## 功能状态

| 功能 | 本次交付状态 | 需要说明的边界 |
| --- | --- | --- |
| SA5041 USB 读取 | 沿用已联通过的板端实现 | 识别模式、读取数字并根据回复解析倍率；并非所有模式和所有量程都已逐项实测 |
| SDS1202X 测量与截图 | 沿用已联通过的实现 | 支持两通道的选定标量参数及 SCDP 图片；不包含波形原始采样点导出 |
| DG4102 信号源 | 板端代码与 HOST2 绑定入口齐全 | 已有仪器参数配置/回读验证；缺少充分的板端实机及真实电输出验收证据，不标为验收完成 |
| 摄像头 SPI 预览 | 历史实机已显示，用户反馈约 28 ACK 帧/秒 | 请求 8 MHz 不等于测得的总线时钟；浏览器帧率另计 |
| 网页冻结、标注、保存及电脑布局 | 当前最终网页与对应 SPI 固件一并提供 | 已有离线交互与响应式检查；仍需团队按最终烧录版本现场复核 |
| 开机自启 | 实现与离线测试保留 | 尚未确认整机冷启动完整验收；需要 SD 挂载、相机驱动与 ESP32 同时就绪 |
| 板端 Paddle-Lite OCR | **待重编译及实机验收** | 旧推理程序的 GLIBC 版本要求高于审核过的工厂 rootfs；本包不放入该已知不兼容程序 |

OCR 的模型转换与部分算法比较已有历史验证，不等同于板端完整图像识别成功。原生预览绕开 OpenCV 采集；OCR 自身仍需要 OpenCV/numpy/pyclipper，不应宣传为全项目无需 OpenCV。

## 本次整理调整

- 采用白名单复制到独立目录，未删除或修改原工作代码。
- 删除电脑端独立验证入口、PaddleOCR 电脑推理引擎、Tesseract 后端及测试数据；保留板端调用需要的共用解析函数。旧函数名称仅用作内部适配钩子。
- ESP32 构建配置只开放最终 `esp32dev_spi_emio` 环境；共享源码内部的 UART/旧采集兼容分支保留以避免重写已运行的传输核心，不提供旧固件、USB 验证页面或旧部署脚本。
- DG4102 不再携带项目仪器的固定序列号。首次绑定由 `LABMATE_DG4102_SERIAL` 指定实际序列号；后续从保存的 HOST2 绑定读取。型号检查、物理路径检查和文件锁保留。
- 不带实际仪器绑定文件、运行输出、个人图片或用户目录绝对路径。
- Python 离线依赖保留原始 dist-info 和第三方许可，不重复携带 wheel 安装包。

这是源码整理包，新增的打包检查与离线回归不代替硬件复测。发布者仍需完成上述待验收项，并统一团队项目的作者和许可信息。
