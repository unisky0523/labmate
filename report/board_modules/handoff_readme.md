# LabMate 板端设备与现场图像模块

本目录是本组成员负责部分的代码交接快照，整理日期为 2026-11-04。面向 Zynq-7010 ARM Linux 和 ESP32，供整合到团队项目。未指定项目许可证或作者署名，由负责开源的同学统一处理；第三方许可原文予以保留。

## 内容

| 目录 | 内容 |
| --- | --- |
| `c_instrument/` | SA5041 万用表、SDS1202X 示波器、DG4102 信号源通信；板端启动器及离线 Python 依赖 |
| `c_camera_link/` | OV5640 原生采集、JPEG 编码、SPI 发送、自启；ESP32 接收、Wi-Fi 热点和网页 |
| `c_vision_lite/` | Paddle-Lite 板端 OCR、推理程序 C++ 源码、转换后的模型及运行库 |
| `c_vision/`、`c_vision_paddle/` | 板端 OCR 实际依赖的定位、结构化解析和后端适配代码，已去除独立电脑端识别入口 |
| `docs/` | 部署、硬件、语音调用接口及验收边界 |
| `tools/` | 最终固件合并、文件校验和重新打包工具 |
| `third_party/` | 第三方声明与许可原文 |

不含电脑端验证程序、NI-VISA 安装包、测试截图与记录、虚拟环境、缓存、云端实验笔记、旧部署 ZIP、其他同学的语音识别工程、Vivado 工程及 FPGA 启动镜像。

## 从哪里开始

1. 阅读 [验收状态](docs/STATUS.md)，区分已实际运行部分与待验收部分。
2. 按 [板端部署](docs/DEPLOY.md) 使用，硬件前提与接线见 [硬件说明](docs/HARDWARE.md)。
3. 语音识别同学按 [接口契约](docs/INTERFACES.md) 调用板端模块，不需要移植电脑验证流程。
4. 修改底层或 ESP32 代码后，按 [构建说明](docs/BUILD.md) 重新生成对应程序。

文件完整性清单为 `MANIFEST.sha256.json`，可执行 `python3 tools/repack.py --verify` 检查。包内 `.sh` 已统一为 LF，ZIP 中保留 Linux 执行权限；若用不保留权限的软件复制到 FAT SD 卡，请按部署文档恢复原生程序权限。

## 重要边界

当前稳定现场预览路线是 **原生 V4L2 → JPEG → 硬件 SPI → ESP32 Wi-Fi → 浏览器**。实测约 28 帧/秒指历史板端 ACK 速率，浏览器显示帧率由网络和终端决定。

OCR 按要求保留，但尚不是已验收的板端功能。已知旧 `smoke_infer` 与工厂系统不兼容，故本包仅保留其源码，须匹配板卡 SDK 重编译。仪器截图与 OCR 摄像头照片属于不同来源；SDS1202X 原始采样点导出尚未实现。

本包不能替代另一位同学提供的 FPGA bitstream、设备树与 Linux 驱动。自启安装会记录实际解压位置，应先确定最终 SD 路径再安装。
