## 现在的操作

- “读取数据”：读取万用表当前模式，以及示波器通道一的峰峰值、频率、有效值，分仪器显示。确认保存本次快照，取消不写实验历史。
- “记录数据”：先确认，再读取两台仪器并归档。
- “连续记录三次数据”：次数可改为 1—100，默认启动间隔一秒；也可说“连续记录五次数据，时间间隔两秒”或“每隔两秒记录一次，共五次”。间隔可为 0—60 秒，支持小数。核对次数/间隔后手动或语音确认一次，执行整批；每轮重新读两台仪表、单独保存，并标注批次序号。仪器耗时超过间隔时顺延，不补赶。执行前可取消，确认执行后等待本批完成。
- “拍一下波形”：先显示“示波器屏幕截图”提示，确认后通过 USB 截图，并复制到实验记录的图片目录。
- “记录电压三点三伏”等人工报数：沿用原来的确认保存流程，来源仍是语音报数。
- 单项报数支持“记录电流一毫安”“记录电压三微伏”“记录频率一兆赫兹”，也可省略开头“记录”；可分别保存或同句包含三种量。单位支持毫、微、纳、皮、千、兆，保留原数值和量级，严格区分 m 与 M。单位未说完整时不自动补成基本单位；单项报数使用对应量的词表复核同一段音频，数值或单位不一致则拒绝保存。模型缺少“毫”，实际用同音“豪”识别并仅在单位位置还原；“赫兹”使用模型已有的“赫 兹”拆词。对应更新说明为 `docs/口述量与单位识别_20261103.md`。
- “撤销上一条数据／记录”：先显示目标数据与时间，确认后将该条历史标为“已撤销”，取消不修改；不再保存一条撤销指令充当执行结果。

## 配置与更新

`instruments.json` 指定两套已验证部署根目录、示波器真实 USB 资源、通道和参数。当前两套仪器源码及各自 vendor/compat 继续位于 SD 卡原目录，没有互相覆盖。

已装 V2 的板卡可以通过 COM6 串口增量更新，不需要拔 SD 卡：

```powershell
& 'D:\fpga amd xinlx\tools\upload_ui_serial.ps1' -PortName COM6 -RealAsr -RecordsOnly -Instruments -PcmLittle
```

`-PcmLittle` 明确发送这一份正式录音源码；日常业务更新仍默认保留板上语音文件。上传前可加 `-PrepareOnly` 检查包内容。

截图预览和语音确认需要新版 Qt 程序。编译后完整更新：

```powershell
& 'D:\fpga amd xinlx\tools\upload_ui_serial.ps1' -PortName COM6 -RealAsr -Instruments -VoiceConfirm
```

该更新明确发送确认适配器和词表，保留板上已验证的 little PCM 文件。不要用旧二进制覆盖新版界面。
